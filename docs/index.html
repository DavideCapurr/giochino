For Claude Code users

The puzzle you procrastinate in — that pings you the second your agent is done.

Kick off a long Claude Code task, then play ShiftBlast. The moment the agent finishes, the game pauses and taps you on the shoulder so you get back to work instead of babysitting a terminal.

Claude Code finishes or needs attention → plugin hook → iCloud signal → game pauses on your iPhone → you're back in flow.

1. Install the Claude Code plugin

/plugin marketplace add davidecapurr/giochino
/plugin install shiftblast-alert@shiftblast

Restart Claude Code, then run /shiftblast-test to verify the link.

2. Get the iPhone app

The free game is a fast block-slide puzzle with Game Center leaderboards and combos. Premium unlocks the AI-agent alert and removes ads. No Mac relay app is required; use the same iCloud account on your Mac and iPhone.
